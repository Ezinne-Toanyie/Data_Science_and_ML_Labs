### 1. Variables and Data Types

In Python programming, a variable holds data to be used in executing a program. A data type tells Python what kind of information a variable holds; text, whole numbers, decimals, or complex numbers.

* Strings Data type are used for text values and are enclosed in quotation marks.
* Numeric Data Types: Python has three numeric types; int, float, complex
* The `type()` function reveals the data type of any variable.

### 2. Sequence

A sequence is an ordered collection of items. Python supports three main sequence types: lists, tuples, and ranges.
* Lists are mutable
* Tuples are immutable
* Ranges generate immutable number sequences.
  
**Commands Executed:**

### 3. Mapping (Dictionaries)

A dictionary stores data as **key-value pairs**. Like a lookup table where you search by a label (key) to retrieve its associated value, values are accessed using their corresponding keys.

##  Key Observations & Lessons Learned

-  Naming variables with trailing underscores (e.g., `list_`, `tuple_`) is a way to avoid conflicts with built-in keywords.
-  Python's `type()` function is a quick and reliable way to inspect what kind of data you are working with; especially useful when debugging.
- The difference between a **list** and a **tuple** comes down to mutability: lists can be updated after creation, while tuples cannot. Choosing the right one matters when data integrity is important.
- Strings use single or double quotes interchangeably.
- Writing clean, well-commented code is best practice in programming.
