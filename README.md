 # DS & ML Labs

> A structured repository documenting weekly Data Science & Machine Learning labs covering Python programming, data analysis, and machine learning concepts with hands-on code and reflections.

---
## 👩‍💻 About

This repository contains weekly lab reproductions, documentation, and reflections completed as part of a structured **Data Science & Machine Learning** program. Each lab is independently reproduced, documented with step-by-step explanations, screenshots of outputs, and key takeaways.

The goal is to build not just technical skills, but the habit of **professional documentation** which is a critical skill in any data-driven career.

---
# 🛠️ Tools & Technologies

- **Python** — Core programming language
- **Jupyter Notebook / Google Colab** — Interactive development environment
- **Git and Github** - Portfolio building and documentation
